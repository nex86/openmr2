# OpenMR2 – MegaRace 2 Revived

An open-source recreation of MegaRace 2 for modern Windows and Linux systems, using the original game data without DOSBox.

**Technical enhancements**

- **GPU-accelerated OpenGL rendering** with high-resolution 3D vehicles and objects.
- **Original and 60 FPS modes**, with rendering separated from game simulation.
- **Optional motion interpolation** for smoother vehicles, objects and camera movement; original video backgrounds retain their source frame rate.
- **Modern graphics options:** MSAA, FXAA, texture filtering and aspect-ratio correction.
- **Retro mode** with original rendering resolutions, integer scaling and selectable scaling filters: Point, HQ2x and BRZ.
- **Revived mode** with enhanced damage and explosion effects.
- **Remappable controller support**, race replays, additional save slots, screenshots and built-in model/video viewers.

Includes the championship, custom single races, original music and Lance Boyle videos. Requires your own game files.
For now Only the English, German and French GOG Versions are supported.
Support for original release CD versions will be added later.
