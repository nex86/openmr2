Retro output filters (0.7.8)
============================
HQ2x: unmodified GLSL single-pass shader and hq2x.png lookup table from
https://github.com/libretro/glsl-shaders/tree/master/hqx
Original source/copyright: Maxim Stepin, Cameron Zemek and Jules Blok.
https://github.com/CrossVR/hqx-shader
LGPL 2.1 or later; full license: HQX-COPYING.txt.
The original Cg shader and include file are included as corresponding source.

xBRZ freescale: unmodified shader from
https://github.com/libretro/glsl-shaders/blob/master/xbrz/shaders/xbrz-freescale.glsl
Contains Hyllian's MIT texel-mapping code and Zenju's GPLv3 xBRZ code/concepts.
Retain all notices within that source. Full GPLv3 license: XBRZ-COPYING.txt.

OpenMR2 integration: src/output_filters.inc and tools/build_output_filters.py.
Only the stage/version preamble and vertex input adapter are supplied by the
port. The two algorithms' original fragment shaders and the HQ2x LUT are
embedded without editing their contents. Both have their original licenses;
this does not resolve the separate inherited-port licensing status.
SHA256SUMS.json records all downloaded source/resource/license files.
The complete third-party files and license texts are distributed under
src/third_party/output_filters/ with the corresponding integration source
src/output_filters.inc and tools/build_output_filters.py.
GPU VIDEO FILTERS (0.7.12)
AMD FidelityFX FSR1: Copyright (c) 2021 Advanced Micro Devices, Inc.; MIT.
Original headers and license: src/third_party/fsr1.
HQx: Copyright Maxim Stepin, Cameron Zemek, Jules Blok; LGPL-2.1-or-later.
Hyllian xBR-lv2: Copyright (c) 2011-2016 Hyllian; MIT.
Original HQ4x LUT/shaders, xBR shader, license texts and provenance hashes:
src/third_party/video_filters. Adapter generators: tools/build_video_fsr.py and
tools/build_video_filters.py. Generated GLSL changes use unsigned zero literals
for GL3.3 FSR constants; HQ scale 4; xBR scale 4, explicit opaque alpha and the
matching TEX0..TEX7 vertex interface. Full upstream source files remain intact.
The LGPL shader stages remain separately identifiable and rebuildable.



Optional recording encoder (0.7.13): FFmpeg/libx264, executed as a separate child.
Local Windows development handoff uses Gyan FFmpeg 9.0.2 essentials (GPLv3),
upstream commit 946fcce07b, downloaded from
https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip (linked by
https://ffmpeg.org/download.html). Original LICENSE/build README accompany
tools/ffmpeg.exe. Linux uses the host FFmpeg package. Any public package that
bundles this encoder must satisfy its and its configured libraries' complete
corresponding-source requirements; the existing private-candidate status is
unchanged. JPEG output uses the already vendored stb_image_write license.
